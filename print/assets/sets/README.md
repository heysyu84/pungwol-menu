# 세트 기본 그림

풍월관 A3 메뉴판용 기본 그림 8종. ChatGPT의 내장 이미지 생성 기능으로 제작했습니다.
원본 PNG를 그대로 보관하며, 투명 알파와 1,024px 이상의 원본 해상도를 유지합니다.

| 파일 | 그려진 구성 |
| --- | --- |
| sparkling-v1.png | 물음표 선택 보틀 1, 365 브뤼 1 |
| richebel-luminous-v1.png | 물음표 선택 보틀 1, 365 브뤼 1, 리쉬벨 브뤼 1·로제 1 |
| richebel-tred-v1.png | 물음표 선택 보틀 1, 365 브뤼 1, 리쉬벨 브뤼 1·로제 1, T 레드 1 |
| blanc-foussy-v1.png | 사용자 첨부 파란 공작 무늬 블랑 푸시 브뤼 3 |

리쉬벨 브뤼/로제는 선택 가능한 구성의 예시이며, 실제 선택을 지정하는 그림이 아닙니다.
선택 보틀은 특정 브랜드를 나타내지 않는 공용 물음표 병입니다.
보틀은 따뜻하고 친근하게, 샴페인은 금빛·은빛 질감으로 표현했습니다.
전체 프롬프트와 수정 지시는 [prompts.json](./prompts.json)에 기록했습니다.

기본 그림은 공용 정적 파일로 제공하여 개인 메뉴판 저장 데이터에 중복하지 않습니다.
HTML 오프라인 저장에는 8종을 모두 포함하고, 인쇄와 SVG 저장에는 사용하는 그림을 포함합니다.
구성 또는 수량이 기본 그림과 달라지면 자동으로 기본 그림을 숨깁니다.
