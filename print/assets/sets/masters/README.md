# 공통 보틀 원본 · v2

Built-in image_gen으로 그린 투명 PNG 원본입니다. 픽셀을 다시 편집하거나 크기를 줄이지 않았습니다.
세트 그림은 동일한 보틀 원본을 SVG로 배치합니다. 세트마다 라벨을 다시 그리지 않으므로
리쉬벨 병목과 선택 보틀의 물음표가 같은 모양을 유지합니다.

| 파일 | 원본 해상도 | 용도 |
| --- | --- | --- |

| richebel-rose-v2.png | 1034 × 1520 | 분홍색 목·분홍 다이아몬드, 흰 방패형 목 라벨과 R 오른쪽 다이아몬드 |

스파클링·리쉬벨 루미너스·리쉬벨 티레드 세트는 같은 2400 × 2200 캔버스와
같은 물음표 보틀 크기로 조합합니다. 리쉬벨 5병 세트는 브뤼 3병·로제 2병입니다.
선택 가능한 리쉬벨 구성의 조합은 예시입니다.

실행본은 원본 PNG 7개와 나머지 세트 그림 3개를 공유해 가져옵니다.
오프라인 HTML에는 이 10개 원본을 포함하고, SVG·인쇄에는 사용하는 그림만 포함합니다.
기본 그림은 개인 메뉴판 저장 데이터에 넣지 않습니다. 사용자 사진은 교체·보관하며
「기본 그림 복원」을 누르면 현재 기본 그림을 다시 사용합니다.

생성·수정 프롬프트는 [prompts-v2.json](./prompts-v2.json), 실제 PNG 해상도와
투명 여백 좌표는 [metadata-v2.json](./metadata-v2.json)에 기록했습니다.
