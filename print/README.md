# 풍월관 A3 인쇄 메뉴판 편집기

인쇄 편집기: https://heysyu84.github.io/pungwol-menu/print/

계정별 웹 저장 편집기: https://pungwol-print-studio.heysyu457310.chatgpt.site

`index.html`에는 편집 코드, 벡터 테두리, Pretendard Variable 원본·영문 필기체와 폰트 라이선스가 포함됩니다. 기본 세트 그림 8종은 `assets/sets/`에 제공하고, 편집기에서 오프라인 HTML로 저장하면 모든 그림을 한 파일에 포함합니다. 기존 메뉴/레시피 파일은 그대로 두고 `/print/`에 추가합니다.

- 기본 세트 그림 8종: 수량별 보틀·샴페인 구성, 선택 보틀 물음표, 사용자 첨부 파란 문양 블랑 푸시와 리쉬벨 방패형 병목 라벨
- 리쉬벨 브뤼/로제는 흰 방패형 병목 라벨과 R 오른쪽 다이아몬드를 새 첨부에 맞춰 그림. 물음표 보틀은 같은 원본과 같은 상대 크기로 세 보틀 세트에서 재사용
- 사진 교체·기본 그림 복원·숨기기. 기존 업로드 사진 유지, 구성·수량 변경 시 맞지 않는 기본 그림 자동 숨김
- 세트 가격 박스 바탕·테두리·글자색 일괄 변경, 현재 페이지와 모든 세트 페이지 적용, 자동 명도 글자색
- 설정 5개 탭: 내용 / 글꼴 / 색·테두리 / 사진 / 페이지·배치. 주제별 접기·펼치기와 설정 검색
- 대제목 크기: **글꼴 → 일괄 글자 크기 → 페이지 대제목 크기**. SET MENU·DRINKS & BOTTLES 등 모든 페이지 공통, mm 단위(1mm ≈ 2.83pt)
- A3 가로/세로 인쇄, PDF 인쇄, SVG·JSON·오프라인 HTML 내보내기
- 메뉴/가격/세트 조합/한글·영문 서체/카테고리 박스/구분선/제목 장식 편집
- Pretendard Variable v1.3.9 원본 WOFF2와 SIL OFL 라이선스 내장. 가변 굵기 및 Bold 700 프리셋 제공, 설치·인터넷 없이 HTML·SVG·인쇄에 사용
- Acumin Variable ExtraCondensed Bold 프리셋(700·폭 50%) 및 본인 Adobe 웹프로젝트 CSS 연결. Acumin Variable Concept 원본은 임의 다운로드·내장하지 않음. 본인의 `https://use.typekit.net/xxxxxxx.css` 주소·사용권과 인터넷 필요. 실제 Acumin이 로드되지 않으면 인쇄를 중단
- **글꼴 → 직접 쓰는 폰트 · Adobe 연결**에서 주력 조합 적용과 설치된 한글/영문 폰트 이름 직접 지정. 파일을 읽거나 복사하지 않으며 다른 PC에서도 해당 폰트 설치 필요. Adobe URL과 직접 지정 이름은 JSON·HTML·웹 저장에 보관
- 주력 조합 버튼을 누를 때만 Pretendard Bold / Acumin EC Bold로 연결. 기존 저장 서체를 자동 교체하지 않고 크기·금액·구성·사진·배치는 보관. Bold 프리셋은 고정 700
- 다섯 기본 페이지: DRINKS, BOTTLES & SETS, SETS ONLY, DRINKS & BOTTLES, SET MENU
- SET MENU: 왼쪽 보틀 세트 3개, 오른쪽 샴페인 2열 × 3칸. 좌하단 추가요금표·우하단 VIP 세트
- 추가요금표는 등급별 첫 줄에 이름·추가금, 둘째 줄에 주류 목록. 예비칸과 업로드 안내는 새 배치에서 제거
- 페이지의 하단 배치 선택에서 이전 로고 배치를 사용할 수 있으며 기존 업로드 그림은 보관
- 샴페인 가격 크기 일괄 설정과 가격 박스 표시/숨김, 사진칸 가로 폭 10% 확대
- 세트명 영문/구성 영문의 공통·개별 pt 분리, 등급명/추가금 글자 크기와 정렬, 만원 문구 생략
- 영문만 있는 첫 번째 세트명에도 영문 크기 적용. 세트별 공통 영문 크기 사용과 디자인의 영문 세트명 일괄 연결 지원
- 세트명 한글·영문 굵기 적용, 표시되는 이름의 언어에 맞춘 세트명 pt 입력
- 일괄 크기를 변경하면 해당 종류의 개별 크기보다 우선 적용. 이후 개별 조절과 실행 취소 가능
- 보틀 금액 박스의 영문 등급명 글꼴·굵기·크기와 금액 일괄 크기, 추가요금 안내의 영문 등급명 글꼴·굵기·크기와 추가금 크기 별도 조절
- 추가금액 선택 주류 목록은 보통·중간·세미볼드·볼드·아주 굵게 선택. 등급명과 독립 적용하며 인쇄·백업·재열기에 보관
- 보틀 세트·선택일람 공통 바탕색/테두리색과 ㄴ자 통합 박스 켜기/끄기. 샴페인 영역의 세로 구분선은 선택일람 위에서 끝남
- ㄴ자 통합 박스의 추가금 칸은 통합 테두리와 X/Y 기준선을 공유해 연결부의 단차 제거. 글씨의 기본 오른쪽 여유 6mm, 0–20mm 조절 가능. 추가금 박스는 각 상위 행 높이를 끝까지 채우며 금액 중앙 정렬. 수동 이동·배율도 반영
- 추가금 박스는 기본 절각 장식: 10% 은은한 바탕, 가는 절각 선, 큰 칸의 작은 마름모. 가는 라인/투명 바탕과 기존 단색 채움도 선택 가능. ㄴ자 해제·세트 전용·보틀 합본 등 모든 세트 레이아웃에 같은 디자인 적용
- 디자인 위치: **색·테두리 → 보틀·선택일람 박스 → 추가금 박스 디자인**. 색은 선택한 디자인의 바탕·선·장식에 적용, 금액 글자는 실제 바탕에 맞춰 가독성 유지
- 「추가금 칸이 행 높이를 채움」은 ㄴ자 해제·다른 세트 페이지·왼쪽/오른쪽 배치에도 적용. 같은 세로형 절각 칸과 중앙 금액을 사용하며 해제하면 작은 배지로 전환. 목록은 오른쪽 칸과 겹치지 않도록 줄바꿈
- SET MENU 추가금 배지는 등급명 왼쪽·두 줄 중앙에 정렬. 왼쪽/오른쪽 배치 선택과 배지 바탕색 변경, 금액 글자 명도 자동 조절
- 세트·카테고리 공통/개별 내부 여백과 선택 안내 추가 여백(mm)
- 마우스·터치 배치, 실행 취소/다시 실행, 기기에 자동 저장

GitHub Pages에는 저장 서버가 없어 이 실행본은 해당 브라우저에 저장합니다. 다른 PC에서 자동 복원하려면 상단 **웹 저장 편집기**를 이용합니다. 두 실행본 사이의 편집 내용은 **저장 · 불러오기 → JSON 백업**으로 옮길 수 있습니다.

이번 업로드에는 개인 계정의 웹 저장 내용을 넣지 않습니다. 첨부 제품 사진은 요청하신 기본 그림 제작의 참고 자료로 사용하며, 사용자의 메뉴판에 직접 업로드한 사진은 공개 실행본에 넣지 않습니다. 같은 계정의 기존 웹 저장 내용은 웹 저장 편집기에서 계속 복원됩니다.

기존 문서는 현재 편집한 SETS ONLY의 세트·가격·사진·선택 주류를 복사해 새 SET MENU 페이지를 한 번 추가합니다. 기존 페이지는 유지하며 각 사본은 독립적으로 편집할 수 있습니다.

검증: 자동 검사 127개, A3 양방향·가격 형식별 출력 형상, 기본 그림과 수량 대응·복원/숨김/실행 취소·일괄 박스 색·오프라인 그림 포함·저장·다른 PC 복원. 공통 보틀 PNG 재사용·물음표 크기·정확한 병 수와 선택일람 간격·전체 높이 금액 칸도 검증했습니다. 연결부의 좌측/상단 일치·수동 배율과 세 가지 추가금 디자인의 전체 레이아웃 적용, 실제 바탕 대비 4.5 이상의 금액 글자색, 기존 색·배치·가격의 다른 PC 복원을 확인했습니다. 밝은/검정 메뉴판의 그림 배치를 SVG 렌더링으로 확인했습니다. 실제 브라우저 인쇄창은 개발 환경에서 확인하지 못했습니다.

이번 변경은 모든 세트 배치의 전체 높이 추가금 칸, Pretendard 원본 바이트·가변 글꼴·700 및 Acumin 700/50% 스타일, 직접 폰트 이름·공식 Adobe URL 검증, 서체별 폭 계산, 실행 취소·웹 저장·이전 버전 보관을 추가 검증했습니다. 실제 Adobe 프로젝트의 Acumin 연결과 브라우저 인쇄창은 사용자 CSS 주소가 없어 확인하지 못했습니다. Pretendard 원본 출처와 라이선스는 `assets/fonts/pretendard-source.json`, `assets/fonts/pretendard-OFL.txt`에 제공합니다.
